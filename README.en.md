## Featured Projects

### MavePOS
100% offline Windows desktop POS and multi-store ERP suite running in production across two retail branches (~5,500 SKUs and 1,200+ monthly sales per store).

- Isolated Electron architecture with SQLite WAL, write-through RAM catalog cache (< 15 ms p95 up to 50,000 SKUs), and commercial hardware integration (HID, ESC/POS, Windows Spooler RAW, RJ11 drawer).
- Serverless multi-store synchronization ($0/month cloud cost), partial transfers, and consolidated catalog homologation.
- 1,118 automated tests (99 suites) and 390/390 WCAG AA audit.

**Stack:** TypeScript, React, Electron, SQLite (WAL), Zustand, Tailwind CSS.

[Technical showcase (closed-source)](https://github.com/cristobal-nan/mavepos-showcase/blob/main/README.en.md) · [Case study](https://cristobal-nanjari.vercel.app/en/projects/mavepos)

### Academic Attendance System (UDP)
Full-stack attendance tracking platform for web, Android, and iOS featuring cryptographically signed dynamic QR tokens (30 s TTL), real-time WebSocket confirmation, early-warning analytics, and

**Stack:** Python, FastAPI, Flutter, Next.js, TypeScript, Firebase (Auth, Firestore, FCM).
