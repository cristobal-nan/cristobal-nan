## Featured Projects

### MavePOS
Windows desktop POS and multi-store ERP suite featuring local offline operation and deferred branch synchronization. Deployed across two retail branches (~5,500 SKUs per store), with one branch recording 1,200+ monthly sales.

- Modular Electron architecture with SQLite (WAL), in-RAM catalog search (< 15 ms p95 on F2/F10 typing up to 50,000 SKUs), and commercial peripheral integration.
- Multi-branch synchronization without a custom backend server, partial warehouse transfers, and consolidated catalog homologation.
- 1,118 passing automated tests (99 suites) and automated UI contrast/stability checks (see methodology in the showcase).

**Stack:** TypeScript, React, Electron, SQLite (WAL), Zustand, Tailwind CSS.

[Technical showcase (closed-source)](https://github.com/cristobal-nan/mavepos-showcase/blob/main/README.en.md) · [Case study](https://cristobal-nanjari.vercel.app/en/projects/mavepos)

### Academic Attendance System (UDP)
Full-stack classroom attendance platform for web, Android, and iOS featuring signed dynamic QR tokens, real-time WebSocket confirmation, threshold-based alerts, and bidirectional Canvas LMS integration. Degree thesis (2025) piloted across 5 university sections (~40 students per section).

**Stack:** Python, FastAPI, Flutter, Next.js, TypeScript, Firebase (Auth, Firestore, FCM).

[Repository](https://github.com/cristobal-nan/academic-attendance-system/blob/main/README.en.md) · [Case study](https://cristobal-nanjari.vercel.app/en/projects/udp-attendance)
